# Staff Kit v2.0.3

## Highlights
- Add owner-aware asset import for workbook-style `Available` and `Laptop` sheets.
- Let IT review and edit owner data before assigned laptop rows become official.
- Create active laptop ownership through `assets + asset_loans` instead of storing assignment only as free text.
- Render employee `Computer Name` from active laptop loans, including multiple laptops per employee.
- Stabilize the employee laptop query path so derived computer-name ordering is deterministic and duplicate checks work per machine.

## What Changed
- `Available` rows now import serialized warehouse assets into `in_stock`, with blank serial number allowed.
- `Laptop` rows now resolve the employee against the imported employee master and only import successfully when the owner is resolvable.
- Name/team mismatches remain reviewable warnings; unresolved owner rows stay out of the success count for manual follow-up.
- The employee table `Computer Name` column now shows derived values like `ASWVNLAP293` or `ASWVNMACPRO010`, with multiple laptops rendered on separate lines.

## Verification

- `node --experimental-strip-types scripts/employee-computer-name-rules.test.ts`

## Notes
- `Available` rows do not require owner resolution.
- `Laptop` rows with unresolved employees are intentionally excluded from the successful import set.
- `Assign Report` by employee or team is still deferred to a later slice.
