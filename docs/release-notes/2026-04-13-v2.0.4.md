# Staff Kit v2.0.4

## Highlights
- Replace the old asset import wizard with a shared import shell across settings-driven import flows.
- Add direct asset preview and import commands inside the new shared shell workflow.
- Keep the compact asset dashboard layout improvements on mainline.
- Restore EE list edit availability when a valid user session exists but local account metadata is still hydrating.

## What Changed
- Import flows now share one shell contract, drawer surface, and state model instead of separate ad hoc wizard wrappers.
- Asset import review now supports direct preview/import commands with updated copy and shared-shell tests.
- The compact asset dashboard styling remains integrated with the newer shared import surfaces.
- Employee table edit gating now follows authenticated session state, not `activeAccount` hydration timing.
- Auth capability derivation is covered by a dedicated regression script so the EE Edit button does not silently regress again.

- `node scripts/employee-computer-name-rules.test.ts`
