# Staff Kit v2.0.10

## Fixes

- Added the Employee list MSSQL update flow for `AzureAD` accounts.
- Fixed AzureAD values not being written when updating an existing employee record.
- Enabled encrypted MSSQL connections with trusted certificates.
- Added MSSQL connection timeout, retry handling, and clearer network/TLS errors.
- Added an edit action for Asset Dashboard column settings.

## Release Packaging

- Windows installers do not bundle the WebView2 Runtime offline installer. Staff Kit expects WebView2 Runtime to already be available on the target machine.

## Validation

- `npm run check:quality`
- Targeted MSSQL Rust tests
