# Staff Kit v2.0.11

## Fixes

- Split active employee laptop loans into separate Device 1 and Device 2 columns.
- Fixed Employee List device editing so each device slot stores one computer name.
- Persisted Device 1 and Device 2 edits, including explicit clearing of a slot.
- Closing a removed device slot now returns the asset to `in_stock` and closes its active loan.
- Normalized imported comma- and line-separated computer names into the two device slots.
- Preserved search and duplicate detection across both device columns.

## Release Packaging

- Windows installers do not bundle the WebView2 Runtime offline installer. Staff Kit expects WebView2 Runtime to already be available on the target machine.

## Validation

- `npm run check:quality`
- `npm run test:tauri`
- `node --experimental-strip-types scripts/employee-computer-name-rules.test.ts`
