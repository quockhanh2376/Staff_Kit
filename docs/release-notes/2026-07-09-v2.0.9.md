# Staff Kit v2.0.9

## Fixes

- Added a clear button inside the Employee list search box.
- Improved the Employee list MSSQL update action so it shows success/error feedback and resets the list filters after a successful update.
- Fixed Asset Import for asset lists that provide `Computer Name` but do not include `Asset Name` / `Display Name`.

## Release Packaging

- Windows installers no longer bundle the WebView2 Runtime offline installer. Staff Kit now expects WebView2 Runtime to already be available on the target machine.

## Validation

- `npm run typecheck`
- `npm run check:quality`
- Targeted Rust asset import tests
