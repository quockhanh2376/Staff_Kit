# Staff Kit v2.0.2 Local Test Release

## Scope
- Stabilize the desktop Borrow/Return line after the archived QR-return merges.
- Keep the current LAN-only Borrow/Return phone flow on the cleaned mainline path.
- Clarify admin review wording so IT sees one shared Borrow/Return review queue.

## What To Test On Local Machine
- Open the desktop app and confirm the app shows version `2.0.2`.
- Scan the fixed LAN QR from a phone on the same Wi-Fi/LAN.
- Submit both a Borrow request and a Return request through the phone page.
- In desktop admin review, confirm the queue badges, detail header, approve button, reject button, and rejection placeholder all match the selected request type.
- Approve and reject sample requests to confirm no regression in stock/loan mutation.

## Known Limits
- LAN-only flow: phone and ST machine must stay on the same network.
- If host/port changes, restart the desktop app before testing the refreshed QR URL.
- Dev reset auto-seed is still design-only in this release; it is not part of `v2.0.2`.
