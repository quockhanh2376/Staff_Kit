# Staff Kit v2.0.5

## Highlights
- Fix the EE list edit flow so editable cells open on single click after entering edit mode.
- Keep `Computer Name` read-only while making the edit interaction discoverable in the table UI.
- Preserve the shared asset import shell and compact asset dashboard work shipped in `v2.0.4`.

## What Changed
- Employee table cells now enter edit mode on single click as well as double click.
- The EE list footer now explains that editable cells can be clicked directly and that `Computer Name` stays read-only.
- A lightweight UI guard was added to stop regressions where the `Edit` button toggles mode but cells do not open for editing.
