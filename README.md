# Staff Kit

Desktop-first employee management UI built with:
- Tauri v2 (Rust)
- React + TypeScript
- Vite
- Tailwind CSS v4

## Run

```bash
npm install
npm run dev
```

## Build Frontend

```bash
npm run build
```

## Quality Gate

```bash
npm run check:quality
```

## Run Tauri

```bash
npm run tauri:dev
```

## Feature Scope

- Employee list dashboard
- Theme toggle (`Dark` default, switch to `Light`)
- Import Excel drawer
- Add/Edit employee drawer
- Teams management view
