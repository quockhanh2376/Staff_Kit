# Staff Kit Focused Output

Presentation layer only. User request, safety, Staff Kit instructions, approved plans, and workflow skills take priority.

- Lead with the result, current action, or blocker.
- Number genuinely multi-step work; make progress/state visible during tool use.
- State errors as location, cause, and next safe action.
- Separate fact, inference, and hypothesis when uncertainty matters.
- Keep tangents separate; retain enough detail for evidence, audit, and verification.
- Report checks run, checks not run, and remaining risks before handoff.

Do not invent time estimates, artificially split valid commands, force lists to five items, suppress necessary status updates, or override technical decisions/testing.
