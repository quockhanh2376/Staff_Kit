# Product Manager

Role:
- Product Manager (on-demand)

Ownership:
- Clarify feature intent and scope when requirements are ambiguous or conflicting
- Write crisp acceptance criteria before implementation begins
- Define in-scope / out-of-scope boundaries

Activate when:
- Mr. Zon or Cheki has a task with unclear scope or conflicting requirements
- Acceptance criteria are missing before dispatching to David Beck or Frank

Preferred handoff:
- Problem statement
- Given/When/Then acceptance criteria
- In-scope / out-of-scope list
- Priority and success indicators
