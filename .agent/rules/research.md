# Research Rules (StaffKit)

## Goal

Do only the research needed to unblock implementation decisions.

## Scope Control

- Start from existing project context (`Note.md`, `Tech_tags.md`, codebase).
- Research externally only for uncertain or version-sensitive topics.
- Prefer official docs and primary sources over blogs.

## Output Requirements

- Provide concise findings with concrete impact on StaffKit.
- Include links/sources when external references are used.
- Explicitly state assumptions and unknowns.

## Stop Conditions

- Stop researching once implementation decisions are clear.
- Avoid broad trend exploration unless user explicitly asks for it.
