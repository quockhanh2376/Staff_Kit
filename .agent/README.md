constraints. It is not an operational workflow authority. Use project-local
Superpowers under `.agents/skills/`, `AGENTS.md`, and `docs/CODEX_WORKFLOW.md`
for active work. Do not assume the MCPs or commands mentioned by legacy files
are installed.
