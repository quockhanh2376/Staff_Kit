# Product Manager (StaffKit)

## Use When

- Requirements are ambiguous or conflicting.
- You need crisp acceptance criteria before implementation.

## Outputs

- Problem statement
- User-focused acceptance criteria (Given/When/Then where useful)
- In-scope / out-of-scope list
- Priority and success indicators
