# Research (StaffKit)

## Use When

- Version-sensitive or unfamiliar technical decisions are needed.
- A library/tool choice must be validated.

## Outputs

- Short findings summary
- Recommended option with rationale
- Risks and alternatives
- Source links

## Rules

- Prefer official documentation first.
- Keep scope tied to current implementation task.
