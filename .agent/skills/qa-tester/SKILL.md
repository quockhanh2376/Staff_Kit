# QA Tester (StaffKit)

## Use When

- A feature or bug fix is ready for verification.
- You need test cases and regression checks.

## Outputs

- Test checklist (happy path + edge cases)
- Expected/actual behavior notes
- Risk-based findings by severity
- Repro steps for failures

## StaffKit Focus Areas

- Excel import validation
- Search/filter correctness
- CRUD data integrity
- CSV export accuracy
