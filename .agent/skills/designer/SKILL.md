# Designer (StaffKit)

## Use When

- Designing new screens or interaction flows.
- Improving clarity/usability of current UI.

## Outputs

- Screen structure and component hierarchy
- Interaction states and feedback behavior
- Visual consistency guidance
- Accessibility and responsive notes

## StaffKit Defaults

- Prioritize operational clarity over visual complexity.
- Optimize table/form flows for daily data operations.
